Ahaan Thai Entwickler Tools

Hier möchte ich die öffentlichen Datenschnittstellen von ahaan-thai.de vorstellen. Die kompletten Inhalte des Projekts stehen im JSON-Format bereit und lassen sich so in eigene Anwendungen, Skripte oder KI-Tools einbinden. Die folgenden drei APIs liefern jeweils strukturierte Daten zu einem Teilbereich von ahaan-thai.de.

Thai Food Encyclopedia API

Diese Schnittstelle stellt das komplette Thai Food Lexikon von ahaan-thai.de im JSON-Format bereit. Sie enthält strukturierte Daten zu hunderten von thailändischen Gerichten mit detaillierten Informationen wie einer Beschreibung des Gerichts, deutschen und englischen Übersetzungen, Thai-Namen, regionalen Zuordnungen und Links zu Rezepten.

Thai Food Dictionary API

Diese API stellt das Ahaan Thai Wörterbuch im JSON-Format bereit. Dieses enthält Thai-Begriffe aus der Küche und unterteilt diese in verschiedene Kategorien (wie zum Beispiel Gewürze, Gemüse, Fleisch, Zubereitungsarten). Jeder Eintrag enthält das Wort auf Thai, deutsche und englische Übersetzungen sowie Romanisierung in deutscher und englischer Schreibweise. Das Wörterbuch ermöglicht es, thailändische Küchenbegriffe systematisch nachzuschlagen und zwischen Thai, Deutsch und Englisch zu übersetzen.

Thai Cook Book Library API

Diese Schnittstelle stellt meine Sammlung thailändischer Kochbücher und die darin enthaltenen Rezepte im JSON-Format bereit. Jedes Kochbuch enthält zwei Bereiche: info mit Metainformationen zum Buch (Autor, Beschreibung, Verlag, ISBN, Erscheinungsjahr, Schwierigkeitsgrad sowie Bild- und Shopping-Links) und recipes mit allen Rezepten des Buches, die ich bereits erfasst habe. Die Bibliothek enthält für jedes Rezept Informationen wie Seitenzahlen, Zuordnung zu einer Region, thailändische Schrift, deutsche und englische Titel sowie Romanisierungen. Zusätzlich sind Bildpfade und URLs zu den einzelnen Rezepten enthalten.

MCP Server und KI Skills

Um diese Schnittstellen auch in KI-Tools verfügbar zu machen, gibt es das MCP-Bundle ahaan-thai.mcpb. Du kannst es herunterladen und per Doppelklick in jedes KI-Tool einbinden, das MCPB versteht, wie zum Beispiel Claude Desktop.

Speziell für Claude Code gibt es einen Plugin-Marketplace mit skript-basierten Skills, die weniger Kontext verbrauchen als ein MCP-Server, da sie nur bei Bedarf geladen werden. Füge ihn mit /plugin marketplace add Der-Reiskoch/ahaan-thai-claude-code-marketplace hinzu und installiere anschließend die Plugins thai-food-dictionary, thai-food-encyclopedia oder thai-cook-book-library.

Über das Tool Skills-CLI lassen sich dieselben Skills mit npx skills add Der-Reiskoch/ahaan-thai-claude-code-marketplace mittlerweile auch für zahlreiche weitere Agenten wie Cursor, Cline oder GitHub Copilot installieren.
