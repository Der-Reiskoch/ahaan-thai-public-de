Krueang Gaeng Som

Paste für saures Curry

เครื่องแกงส้ม Zentralthailand, Südthailand
Currypaste

“Krueang Gaeng Som” ( เครื่องแกงส้ม ) ist eine Paste für saure Currys aus Zentralthailand. Sie wird aus getrockneten Chilis, weißem Pfeffer, Schalotten, Knoblauch, Fingerwurz und Garnelenpaste zubereitet. Die Paste verleiht Currys einen rötlichen Farbton und eine angenehme Schärfe. Sie wird auch “Prik Gaeng Som" ( พริกแกงส้ม ) oder “Nam Prik Gaeng Som” ( น้ำพริกแกงส้ม ) genannt.
